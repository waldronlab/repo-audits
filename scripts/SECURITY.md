# Security Policy

## Supported Versions

Security fixes are applied to the current Bioconductor release branch and
`devel`.

| Branch | Supported |
|--------|-----------|
| `devel` | ✅ |
| Current Bioconductor release (`RELEASE_*`) | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Instead, please open a
[GitHub Security Advisory](../../security/advisories/new) for this repository.
We will respond within 5 business days and aim to publish a fix or advisory
within 90 days of receiving the report.
