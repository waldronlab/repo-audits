This automated PR adds or updates the `CITATION.cff` file using the
[cffr](https://docs.ropensci.org/cffr/) R package, which derives citation
metadata directly from the package `DESCRIPTION` (and `inst/CITATION` if
present).

## Changes
- **Added / updated** `CITATION.cff` – generated by `cffr::cff_write()`

## Why
A `CITATION.cff` file makes it easy for users and tools (GitHub, Zenodo,
Zotero, etc.) to cite your package correctly.

## Customisation
You can further customise the generated file by editing `CITATION.cff`
directly after this PR is merged, or by adding a `cff-version` key block to
`inst/CITATION`. See the
[cffr vignette](https://docs.ropensci.org/cffr/articles/cffr.html) for
details.
