This automated PR adds or updates both `inst/CITATION` and `CITATION.cff` using
the [cffr](https://docs.ropensci.org/cffr/) R package.  Both files are derived
from the same source (`DESCRIPTION`) so they stay in sync with each other.

## Changes
- **Added / updated** `inst/CITATION` – the auto citation in R `bibentry` format,
  equivalent to `citation("pkg", auto = TRUE)`
- **Added / updated** `CITATION.cff` – generated by `cffr::cff_write()`, which
  picks up `inst/CITATION` as the `preferred-citation`

## How citations are handled
- `inst/CITATION` holds the **preferred citation** in R format so that
  `citation("pkg")` returns an up-to-date entry for package users.
- `CITATION.cff` references that same entry as its `preferred-citation` and
  exposes the metadata to GitHub, Zenodo, Zotero, and other tools.
- Both files are regenerated from `DESCRIPTION` on every run, so they remain
  consistent as the package evolves.

## Why
Keeping `inst/CITATION` and `CITATION.cff` in sync ensures that R users and
external tools always see the same, correct citation metadata.

## Customisation
After merging, you can override the auto-generated preferred citation by
manually editing `inst/CITATION` and re-running the workflow (or editing
`CITATION.cff` directly). See the
[cffr vignette](https://docs.ropensci.org/cffr/articles/cffr.html) for
details.
